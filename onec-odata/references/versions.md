# Различия версий платформы

Раздел «Стандартный интерфейс OData» руководства разработчика сравнен по редакциям 8.3.16-8.3.27 и 8.5 (сверка 2026-10-17). Возможности интерфейса между версиями **не менялись**: те же параметры запроса, функции отбора, коды ошибок и операции. Отдельные справочники под версии не нужны.

| Версия | Изменение в документации |
| --- | --- |
| 8.3.17 | исправлены опечатки в примерах (`UTF-8`) |
| 8.3.19 | добавлены примеры: набор записей регистра бухгалтерии по регистратору (GET) и его изменение (PATCH) |
| 8.3.21 | раздел перенесен из 17.2.1 в 17.4, нумерация подразделов сдвинулась; убрана вводная фраза о совместной работе с SOAP- и HTTP-сервисами |
| 8.3.22 | добавлен пример изменения константы; в примерах исправлены GUID и даты |
| 8.3.23, 8.3.25 | перестановка строк в таблицах функций, форматирование примеров |
| 8.5 | ссылка на «Руководство администратора» 8.5 |

Что от версии зависит на практике:

- **Состав интерфейса** зависит от режима совместимости конфигурации, а не от версии платформы: до 8.3.4 включительно публикуются все объекты, новее - только включенные (`publication.md`).
- **Набор параметров виртуальных таблиц** бери из `$metadata` конкретной базы (`odata.sh meta`): на 8.3.16 у регистров накопления есть недокументированный параметр `Dimensions`.
- Изменения поведения платформы описываются в списках изменений версий (V8Update), а не в руководстве; по OData они сюда не сведены.

Ссылки на редакции: `https://its.1c.ru/db/v8316doc#bookmark:dev:TI000001358` (заменить `8316` на нужную версию, для 8.5 - `v85doc`).
