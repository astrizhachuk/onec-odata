# Имена ресурсов, свойств и типов

Источник: «Руководство разработчика», раздел «Стандартный интерфейс OData» (8.3.16: 17.2.1.3-17.2.1.4; с 8.3.21: 17.4.3-17.4.4). Точные имена для конкретной базы - всегда из `odata.sh meta`.

## Имя ресурса

`ПрефиксИмени_ИмяОбъектаКонфигурации[_СуффиксИмени]`. `ИмяОбъектаКонфигурации` - свойство «Имя» объекта метаданных, как в конфигураторе.

| Объект конфигурации | Префикс |
| --- | --- |
| Справочник | `Catalog` |
| Документ | `Document` |
| Журнал документов | `DocumentJournal` |
| Константа | `Constant` |
| План обмена | `ExchangePlan` |
| План счетов | `ChartOfAccounts` |
| План видов расчета | `ChartOfCalculationTypes` |
| План видов характеристик | `ChartOfCharacteristicTypes` |
| Регистр сведений | `InformationRegister` |
| Регистр накопления | `AccumulationRegister` |
| Регистр расчета | `CalculationRegister` |
| Регистр бухгалтерии | `AccountingRegister` |
| Бизнес-процесс | `BusinessProcess` |
| Задача | `Task` |

Перечисления, обработки, отчеты и внешние источники данных отдельными наборами не публикуются. Значения перечислений приходят строкой с именем значения.

Суффиксы имени ресурса:

| Суффикс | Что адресует | Пример |
| --- | --- | --- |
| имя табличной части | все строки этой табличной части всех объектов | `Document_РасходТовара_Товары` |
| `_RecordType` | отдельные записи регистра (а не наборы по регистратору) | `InformationRegister_ПриходныеЦены_RecordType` |
| `_RowType` | тип строки табличной части или набора записей (в `$metadata` и `odata.type`) | `Catalog_Магазины_ТорговыеЗалы_RowType` |
| `/<ВиртуальнаяТаблица>(...)` | функция виртуальной таблицы регистра | `InformationRegister_КурсыВалют/SliceLast()` |

Записи регистров и строки табличных частей как отдельные сущности доступны только на чтение.

## Адрес одной сущности (канонический URL)

| Сущность | Ключ | Пример ресурса |
| --- | --- | --- |
| ссылочный объект | `Ref_Key` (имя ключа можно опустить) | `Catalog_Товары(guid'...')` |
| строка табличной части | `Ref_Key`, `LineNumber` | `Document_РасходТовара_Товары(Ref_Key=guid'...', LineNumber=1)` |
| набор записей подчиненного регистра | `Recorder`, `Recorder_Type` | `AccumulationRegister_ТоварыНаСкладах(Recorder='<guid>', Recorder_Type='StandardODATA.Document_ПеремещениеТоваров')` |
| запись независимого регистра сведений | все измерения и `Period`, если регистр периодический | `InformationRegister_КурсыВалют(Period=datetime'2008-02-05T00:00:00', Валюта_Key=guid'...')` |
| константа | нулевой GUID | `Constant_ИспользоватьИнтеграцию(guid'00000000-0000-0000-0000-000000000000')` |

Состав ключа у регистра бывает неочевидным (`Recorder` + `Recorder_Type` у составного регистратора) - смотри строки `key` в `odata.sh meta`. Если ключей несколько, указываются все, парами `Имя=Значение` через запятую.

`$expand` для одиночной сущности не поддерживается (HTTP 501). Чтобы получить связанные объекты вместе с одним объектом, запрашивай набор с отбором `Ref_Key eq guid'...'`.

## Стандартные реквизиты

Стандартные реквизиты называются по-английски, в том числе в путях «через точку» (`Document_X(guid'...')/Валюта/Description`).

| Реквизит 1С | Свойство OData |
| --- | --- |
| Ссылка | `Ref_Key` |
| ВерсияДанных | `DataVersion` |
| ПометкаУдаления | `DeletionMark` |
| Номер, Дата, Проведен | `Number`, `Date`, `Posted` |
| Код, Наименование | `Code`, `Description` |
| Родитель, ЭтоГруппа | `Parent_Key`, `IsFolder` |
| Предопределенный | `Predefined` |
| НомерСтроки | `LineNumber` |
| Регистратор, Период, Активность | `Recorder` (+ `Recorder_Type`), `Period`, `Active` |
| ВидДвижения (регистр накопления) | `RecordType` |
| набор записей регистра | `RecordSet` |
| значение константы | `Value` |

Набор стандартных реквизитов зависит от объекта и режима совместимости (например, владелец справочника) - проверяй по `meta`.

## Суффиксы свойств

| Суффикс | Смысл |
| --- | --- |
| `<Имя>_Key` | значение ссылочного реквизита (GUID). Отбор по ссылке - только по этому свойству и только литералом `guid'...'` |
| `<Имя>` без суффикса у ссылочного реквизита | навигационное свойство: путь к связанной сущности (`Организация/ИНН`, `$expand=Организация`) |
| `<Имя>_Type` | диспетчеризационное свойство составного реквизита: `StandardODATA.Document_РасходТовара`, `StandardODATA.Undefined` (значение неопределено), для примитивов - `Edm.String` и т. п. |
| `<Имя>` у составного реквизита | значение (`Edm.String`): GUID ссылки строкой или значение примитивного типа |
| `<Имя>_Base64Data` | содержимое реквизита типа ХранилищеЗначения в Base64; `<Имя>_Type` при этом - `application/octet-stream`, `application/xml+xdto` или MIME-тип картинки |
| `<Имя>____Presentation` | представление реквизита (между именем и `Presentation` четыре `_`), как функция `ПРЕДСТАВЛЕНИЕ()` языка запросов |
| `Presentation` | представление самой сущности: `$select=Ref_Key,Presentation` |

Представления:

- не входят в ответ без `$select`, а также при `$select=*` и `$select=**` - их нужно перечислять явно: `$select=*,Организация____Presentation`;
- `$select=*____Presentation` - представления всех реквизитов; `$select=*,*____Presentation` - значения и представления;
- нет в `$metadata`, не поддерживаются для табличных частей целиком и ХранилищаЗначения, недоступны для записи.

Незаполненная ссылка - GUID из нулей, незаполненная дата - `0001-01-01T00:00:00`.

## Соответствие типов

| Тип 1С | Тип OData |
| --- | --- |
| Строка | `Edm.String` |
| Дата | `Edm.DateTime` |
| Число целое | `Edm.Int16`, `Edm.Int32`, `Edm.Int64` |
| Число дробное | `Edm.Double` |
| Булево | `Edm.Boolean` |
| Ссылка, УникальныйИдентификатор | `Edm.Guid` |
| Перечисление | `Edm.String` |
| Ссылочный тип | два свойства: `_Key` (`Edm.Guid`) и навигационное |
| Составной тип | два свойства `Edm.String`: значение и `_Type` |
| ХранилищеЗначения | навигационное свойство, `_Base64Data`, `_Type` |

Прочие типы не поддерживаются: чтение такого реквизита дает ошибку с HTTP 501.

Нотация литералов: `guid'8d04ce3c-6360-11e9-dd92-fa163e8ba11d'`, `datetime'1945-05-09T06:00:00'`, строки в одинарных кавычках, булево `true`/`false`.
