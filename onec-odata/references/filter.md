# $filter

Источник: «Руководство разработчика», раздел «Правила формирования условия отбора» (8.3.16: 17.2.1.5; с 8.3.21: 17.4.5). Формы литералов - в таблице «Литералы в отборе» SKILL.md.

## Операторы

| Оператор | Смысл | Пример |
| --- | --- | --- |
| `eq`, `ne` | равно, не равно | `Description eq 'Главный'` |
| `gt`, `ge`, `lt`, `le` | больше, больше или равно, меньше, меньше или равно | `Цена ge 10` |
| `and`, `or`, `not` | логические | `not (Цена eq 10)` |
| `add`, `sub`, `mul`, `div` | арифметика | `Цена add 5 gt 10` |
| `( )` | группировка | `(Цена add 5) gt 10` |
| `/` | навигация к реквизиту связанной сущности | `Контрагент/ИНН eq '7700000000'` |

Приоритет по убыванию: `( )`, `/`, унарный `-`, `not`, `mul`, `div`, `add`, `sub`, `gt`, `ge`, `lt`, `le`, `eq`, `ne`, `and`, `or`. Одинаковый приоритет - слева направо.

## Функции

Функции применимы в `$filter` и `$orderby`.

Строковые:

| Функция | Смысл | Пример |
| --- | --- | --- |
| `concat(s1, s2)` | конкатенация | `concat(concat(Город, ', '), Страна) eq 'Москва, Россия'` |
| `startswith(s1, s2)` | `s1` начинается с `s2` | `startswith(Description, 'ООО') eq true` |
| `endswith(s1, s2)` | `s1` заканчивается на `s2` | `endswith(Производитель, 'ООО') eq true` |
| `substringof(s1, s2)` | `s1` - подстрока `s2` (порядок аргументов обратный привычному) | `substringof('Октябрь', Производитель) eq true` |
| `substring(s, i)`, `substring(s, i, n)` | подстрока с позиции `i` (длиной `n`) | `substring(ИНН, 1, 2) eq '77'` |
| `like(s, шаблон)` | шаблон как у `ПОДОБНО` языка запросов (`%`, `_`, `[...]`, `[^...]`) | `like(Description, '%Молоко%')` |

Даты:

| Функция | Смысл |
| --- | --- |
| `year`, `quarter`, `month`, `day`, `hour`, `minute`, `second` | часть даты: `year(Date) eq 2025` |
| `dayofweek`, `dayofyear` | день недели, день года |
| `dateadd(d, 'тип', n)` | `d` плюс `n` единиц: `second`, `minute`, `hour`, `day`, `month`, `quarter`, `year` |
| `datedifference(d1, d2, 'тип')` | `d2 - d1` в единицах типа: `datedifference(Произведен, ГоденДо, 'day') gt 10` |

Прочие:

| Функция | Смысл |
| --- | --- |
| `cast(expr, 'Тип')` | приведение к типу: `String`, `Number`, `Boolean`, `Date` или имя сущности (`Catalog_Товары`, `Document_Накладная`) |
| `isof(expr, 'Тип')` | `true`, если значение имеет указанный тип |
| `round(n)` | округление до целого |

Не поддерживаются: `length`, `indexof`, `replace`, `tolower`, `toupper`, `trim`, `years`, `days`, `hours`, `seconds`, `floor`, `ceiling`, а также сравнение с реквизитом типа ХранилищеЗначения. Неподдерживаемая функция или неверное число аргументов - внутренний код ошибки 21.

## Составные реквизиты

Значение составного реквизита сравнивается с ссылкой только через `cast` с указанием типа:

```
Recorder eq cast(guid'7a3c9e15-4e91-11f0-8b2d-0050568a1f42', 'Document_ПеремещениеТоваров')
```

Проверено на стенде (8.3.16, регистр накопления): `cast` вернул 6 записей, тот же GUID строкой (`Recorder eq '<guid>'`) - 0 без ошибки, `Recorder eq guid'<guid>'` - ошибку «Нельзя сравнивать поля». Документация также прямо говорит, что сравнение составного реквизита с `guid'...'` всегда дает пустой результат.

Отбор по типу значения - `isof(ДокументыПрихода, 'Document_ПриходнаяНакладная')`.

Условие на реквизит объекта, на который ссылается составной реквизит, - через `cast` по цепочке. Документы `МаршрутныйЛист`, у которых `ОснованиеОтгрузки` - `Накладная`, а у нее `МестоОтгрузки` - склад с названием «Основной в Москве»:

```
cast(cast(ОснованиеОтгрузки, 'Document_Накладная')/МестоОтгрузки, 'Catalog_Склад')/Название eq 'Основной в Москве'
```

Отбор по реквизиту типа УникальныйИдентификатор (не ссылка) - обычное сравнение `ИмяРеквизита eq guid'...'`.

## Отбор по строкам табличной части

Лямбда-функции по коллекции: `any` - хотя бы одна строка удовлетворяет условию, `all` - все строки. `any()` без аргументов - коллекция не пуста.

```
Товары/any(d: d/Цена gt 10000)
Товары/all(d: d/Цена lt 10000)
Товары/any(d: d/Номенклатура_Key eq guid'...')
```

## Отбор и права доступа

Если в выборку попадают записи, закрытые ограничением доступа к данным (RLS), запрос падает с ошибкой прав (по документации - HTTP 401, внутренний код 20). Добавь `--allowed-only`: вернутся только разрешенные записи. Параметр работает только для GET-запросов к наборам сущностей.
